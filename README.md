# Claude Code Skills

Local Claude Code skills for this project.

## Skills

### conventional-commit

Converts raw change descriptions or git diffs into [Conventional Commits](https://www.conventionalcommits.org/) formatted messages.

**Triggers:** "format a commit", "conventional commits", "what's a good commit message for this", paste a diff and ask what to commit it as.

**Output:** ready-to-paste commit message block.

**Example:**

> "I fixed the login form crashing when users type an email with a plus sign"

```
fix(auth): allow plus signs in email addresses

The address validation regex was rejecting RFC-compliant emails
containing `+`, causing the login form to reject valid accounts.
```

---

### seo-report-formatter

Formats raw SEO audit findings (from `FULL-AUDIT-REPORT.md` / `ACTION-PLAN.md`) into a clean, client-ready Markdown report.

**Triggers:** "format the audit report", "make a clean MD report", "client report from audit", "export SEO results to markdown".

**Input:** `FULL-AUDIT-REPORT.md` and/or `ACTION-PLAN.md` in current directory (generated by `seo-audit` skill), or raw findings pasted directly.

**Output:** `SEO-REPORT-[domain]-[YYYY-MM-DD].md` with:
- Score table with 🔴🟡🟢 status indicators
- Executive summary
- Findings by category
- Prioritized action plan (Critical / High / Medium / Low) with Impact + Effort columns
